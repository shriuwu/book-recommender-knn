How It Works

KNN-based collaborative filtering finds users with similar tastes and recommends books they loved.

01
Collect Ratings
Load user–book rating pairs from the GoodBooks-10K dataset (1–5 stars)
02
Cosine Similarity
Compute similarity between users based on their rating vectors
03
Find Neighbours
Identify k=10 most similar users to the target user
04
Predict Ratings
Aggregate neighbour ratings to estimate scores for unread books
05
Recommend
Return the Top-N books with the highest predicted ratings

KNN Models Compared

Three variants of KNN-based collaborative filtering, each building on the last.

⚡
KNNBasic
The baseline approach. Uses raw ratings from k nearest neighbors with no bias correction whatsoever.
RMSE~0.89
MAE~0.70
🎯
KNNWithMeans
Adjusts predictions to account for each user's personal average rating bias (some users always rate high/low).
RMSE~0.86
MAE~0.68
Best
🏆
KNNBaseline
Corrects for global average + user bias + item bias before applying KNN. Achieves the lowest error rates.
RMSE~0.83
MAE~0.65
